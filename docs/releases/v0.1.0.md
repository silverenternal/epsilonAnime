# epsilonAnime v0.1.0

首个公开版本。`epsilonAnime` 是一个运行在现代终端中的网易云音乐可视化器：

- 粘贴网易云歌曲链接即可获取流式音频、封面、歌词与评论。
- 512×512 OpenCV 封面分析、彩色盲文/混合半块渲染和高分辨率粒子重建。
- 基于实时 BPM、频谱、能量与歌词计算场景，由生成宏驱动的复变函数、谱函数、球谐、贝塞尔与 3D 数学动画。
- 歌词同步、日文罗马音、评论弹幕、2D 声学热图、扫码登录和完整音乐库。
- 可拖动缩放的多窗口工作区、毛玻璃叠加、脏矩阵渲染和内嵌 PTY Shell。
- 三平台 CI、依赖审计、MIT 许可证和可复现的跨平台发布包。

## 运行

需要 Python 3.12 和 [uv](https://docs.astral.sh/uv/)。

macOS / Linux：

```bash
tar -xzf epsilonAnime-v0.1.0-*.tar.gz
cd epsilonAnime-v0.1.0-*
./scripts/run.sh --demo
```

Windows PowerShell：

```powershell
Expand-Archive .\epsilonAnime-v0.1.0-windows-x86_64.zip
cd .\epsilonAnime-v0.1.0-windows-x86_64
.\scripts\run.ps1 --demo
```

首次运行会通过 uv 安装锁定版本的 Python 依赖。联网播放请把 `--demo` 换成网易云歌曲链接。
